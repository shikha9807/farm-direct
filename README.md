# 🌾 FarmDirect

**FarmDirect** is a modern platform designed to bridge the gap between farmers and consumers, enabling direct farm-to-table transactions. By cutting out middle management and traditional brokers, FarmDirect ensures fair pricing for farmers and fresh, high-quality produce for consumers.

---

## ✨ Features

* **Direct Marketplace:** Consumers can browse fresh produce directly from local farms.
* **Farmer Dashboard:** Simple management for inventory, product listings, pricing, and incoming orders.
* **Order Tracking:** Real-time updates on orders from harvest to delivery.
* **Transparent Pricing:** Clear breakdown of costs to ensure maximum profits go back to the farm.
* **Location-Based Search:** Find local farms and seasonal produce near you.

---

## 📖 How It Works

1. Register users (farmers and consumers) in the system.
2. Farmers list their fresh produce along with pricing and quantity.
3. Consumers browse local farms and add items to their cart.
4. Place and verify order details through the platform.
5. Process payment and track the order status from harvest to delivery.
6. Generate receipts and sales reports for farmers and buyers.

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/) (v16.x or higher)
* [Git](https://git-scm.com/)

### Installation

1. **Clone the repository:**

   ```bash
   git clone git@github.com:shikha9807/farm-direct.git
   cd FarmDirect
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Set up Environment Variables:**
   Create a `.env` file in the root directory and add your configuration details:

   ```env
   PORT=5000
   DATABASE_URL=your_database_connection_string
   ```

4. **Run the Application:**

   ```bash
   # Development mode
   npm run dev
   ```
